# Support the development of tokenAtlas

tokenAtlas is intended to be free, open-source desktop software under
Apache-2.0. **Donations are voluntary**. Paying is not required to use
the code, including commercially, report problems or contribute.

The central place for **verified, current** support methods is the official
website: **https://tokenatlas.dev/**.

The site may offer different payment methods or profiles, including
Patronite, Patreon, Ko-fi, Stripe-based payments and Suppi. Only link to
a channel from the website after confirming that the relevant profile and
payment method are actually active. Availability varies; this document
does not claim that every named service is currently accepting payments.

The GitHub repository also contains `.github/FUNDING.yml` for the GitHub
Sponsors button (`KNODEdev`). That configuration is not proof that the
Sponsors profile can already accept contributions; verify activation
before promoting it.

## Three independent ways to support the project

**Individual donations:** one-time or recurring contributions without
mandatory perks, preferential bug fixing or promised delivery dates.

**Organisation sponsorship:** a separate, explicitly agreed arrangement
for public acknowledgement, where appropriate. Sponsors do not control
the project's technical findings, code licence or roadmap decisions.

**Commissioned work:** paid integration, support or bespoke implementation
agreed separately from donations and open-source usage rights. A paid
service does not automatically convey rights to the official brand.

## Financial transparency

Development updates can report shipped changes, verified financial
receipts, transaction fees and actual expenses. Keep these separate from
estimated API-equivalent usage or subscription-cost allocation, which
are not cash invoices. Do not publish supporter identities without consent.
